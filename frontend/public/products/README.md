# 商品展示媒体

`wanderlite.png`（P1003）、`drypack.png`（P1018）、`budgetpack.png`（P1049）复制自
`docs/previews/assets/`，由内置图像生成工具于 2026-09-09 生成。完整生成记录在
`docs/previews/assets/图像生成记录.md`。

这些图片仅展示虚构商品的概念外观，**不是平台商品实拍，不证明某个 SKU 的颜色、尺寸或材质**。
接口始终标记 `image_kind: "illustration"`，页面应保留“商品示意图”标识；切换 SKU 不改变该说明。
没有媒体的商品返回 `image_url: null`、`image_kind: "placeholder"`，由前端展示品类图标或占位内容。

目录内评分与评论数来自版本化评测数据，`rating_is_live` 为 `false`，不得表述为实时评分。

- B 图：台灯、笔记本支架、笔记本、宠物包、饮水机、婴儿浴巾、分装瓶、吹风机、折叠凳、行李箱、旅行三件套、登山杖、眼罩、耳塞、证件包、行李秤。

映射源是 `app/presentation/assets/product-media-v1.json`，由 `python -m scripts.build_product_media` 根据已知目录构建并提交。运行时按精确商品 ID 或 SKU 读取，**不按标题猜图**。新图为同类商品概念图；例如背包的不同容量、不同语言条目可以共用示意外观，不代表它们实际长得一样。

`GET /commerce/product-media` 只公开展示注册表，不包含买家信息；前端统一消费。新搜索结果、历史卡片、收藏、订单、详情及工具结果小卡均可补图，无需重写商品数据库或历史快照。工具输入输出及冻结评测商品集保持原样。真实目录已经提供的图片优先。

本批覆盖 catalog-v3 的 3,440/3,700 件商品，含原有 3 件专属示意图；其余 260 件仍占位。新增/替换图片时需核对商品类型、更新映射和素材文件版本，并验证刷新、错误回退及快照不变性。页面必须保留“商品示意图 · 非实物照片”说明。
